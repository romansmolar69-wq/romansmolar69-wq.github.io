# 📚 Сайт розкладу навчальних занять коледжу

Сучасний, адаптивний та зручний веб-сайт для перегляду розкладу занять студентів коледжу.

---

## 🚀 Як відкрити та переглянути сайт

1. Відкрийте папку:
   `C:\Users\Учень 8\.gemini\antigravity\scratch\college-schedule\`
2. Двічі клікніть по файлу **`index.html`** у будь-якому браузері (Google Chrome, Microsoft Edge, Firefox, Opera).
3. Сайт відкриється локально та повністю готовий до роботи без встановлення додаткових серверів чи бібліотек!

---

## 📂 Структура сторінок проекту

| Файл | Опис |
| :--- | :--- |
| **`index.html`** | **Головна сторінка**: вибір курсу, швидкий пошук, швидкі переходи. |
| **`course1.html`** | **1 Курс**: розклад виключно груп 1 курсу (**Кр-11, Кр-12, Кр-13**). |
| **`course2.html`** | **2 Курс**: розклад виключно груп 2 курсу (**Кр-21, Кр-22, Кр-23**). |
| **`course3.html`** | **3 Курс**: розклад виключно груп 3 курсу (**Кр-31, Кр-32, Кр-33**). |
| **`course-t.html`** | **Відділення Т**: розклад технологічних груп (**Т-1, Т-2**). |
| **`teacher.html`** | **Сторінка викладача**: відкривається при кліку на **назву будь-якого уроку**. Показує ПІБ, кафедру, контакти, аудиторію та **персональний розклад цього викладача**. |
| **`teachers.html`** | **Каталог викладачів**: перелік усіх викладачів із швидким пошуком. |
| **`bells.html`** | **Розклад дзвінків**: час початку, закінчення пар та перерви. |
| **`data.js`** | **База даних**: зручний файл, де зберігаються всі предмети, групи, викладачі та години. |
| **`style.css`** | **Стилі сайту**: сучасний дизайн, адаптивність під телефони та комп'ютери, підтримка друку. |
| **`script.js`** | **Логіка**: фільтрація по групах і днях, миттєвий пошук, динамічне завантаження профілів. |

## ✨ Реалізовані можливості

- 🔗 **Гіперпосилання на уроках**: Натискаючи на назву уроку (наприклад, *"Вища математика"* або *"Основи алгоритмізації"*), ви одразу потрапляєте на сторінку викладача, який веде цей урок.
- 🎓 **Розділи по курсах**:
  - Назви на **1** (Кр-11, Кр-12, Кр-13) → окрема сторінка 1 курсу.
  - Назви на **2** (Кр-21, Кр-22, Кр-23) → окрема сторінка 2 курсу.
  - Назви на **3** (Кр-31, Кр-32, Кр-33) → окрема сторінка 3 курсу.
  - Спеціальні групи **Т-1, Т-2** → окрема сторінка відділення Т.
- 🔍 **Миттєва фільтрація та пошук**:
  - Можна вибрати окрему групу або показати всі групи курсу одночасно.
  - Можна фільтрувати за днем тижня (Понеділок – П'ятниця).
  - Рядок пошуку в реальному часі знаходить предмети, номери кабінетів чи прізвища.
- 👨‍🏫 **Пробні викладачі**:
  - Додано базу пробних викладачів із контактами, аудиторіями та годинами консультацій.
  - Коли з'являться реальні дані, їх можна легко оновити у файлі `data.js`.
- 🖨️ **Друк розкладу**:
  - Кнопка "Роздрукувати розклад" автоматично оптимізує сторінку для друку на А4.

## 🛠️ Як вносити зміни у розклад чи список викладачів

Усі дані винесені в один зрозумілий файл: **`data.js`**.
Вам не потрібно редагувати кожну HTML сторінку окремо — достатньо змінити назву чи викладача в `data.js`, і сайт автоматично оновить усі сторінки!
